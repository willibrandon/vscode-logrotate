# Support

Use the repository's GitHub issue tracker for reproducible bugs and focused feature requests. Search
existing issues first and include the extension version, VS Code version, extension host type
(desktop, remote, or web), workspace scheme, target logrotate version, and a minimal redacted
example.

For parser differences, include both the extension diagnostic code and the output of
`logrotate --version`. Host validation reflects the installed machine and is not interchangeable
with the extension's versioned parser. Never attach production logs, state files, credentials,
private paths, or unredacted account names.

Questions about logrotate itself belong in the
[upstream logrotate project](https://github.com/logrotate/logrotate). Security reports must follow
[SECURITY.md](SECURITY.md).

This is a volunteer project; response times are best effort.
