---
title: Commands
description: Find the Logrotate commands available in the Visual Studio Code Command Palette.
---

Open the Command Palette and type `Logrotate` to find the commands available in the current
workspace.

## Validate with installed logrotate

**Logrotate: Validate Current File with Installed Logrotate** runs the optional host validation
described on the [validation](../validation/) page. It is shown for an eligible Logrotate
configuration in a trusted desktop workspace.

## Restart the language server

**Logrotate: Restart Language Server** stops the current language client and server, disposes loaded
include watchers, then starts a fresh server.

## Show language server output

**Logrotate: Show Language Server Output** opens the Logrotate Language Server output channel
without moving keyboard focus from the editor.

## Open directive documentation

**Logrotate: Open Directive Documentation** opens the reviewed directive reference in the upstream
logrotate manual. Diagnostic quick fixes can offer the same action for a specific directive.
